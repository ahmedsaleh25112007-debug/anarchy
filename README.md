# ANARCHY — موقع العيلة

موقع صفحة واحدة (One Page) بالشعار والحركات، وفيه قسم **بث مباشر** مربوط بـ Kick
بيتحدّث لوحده ويعرض Shenzoe أول ما يفتح لايف.

---

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | كل الكلام والكلام اللي بيتعدل (الأسماء، الرتب، القوانين، اللينكات) |
| `styles.css` | كل التصميم والألوان والحركات |
| `script.js` | اللودر، الشرار، المؤثرات، وقسم البث |
| `live-proxy.js` | سيرفر صغير (اختياري) بيجيب بيانات كيك ويقدّم الموقع |

---

## إزاي تفتحه

أسهل طريقة: دوس دبل كليك على `index.html`.
كل حاجة بتشتغل من غير إنترنت ما عدا:
- خطوط جوجل (لو مفيش نت بيستخدم خطوط الجهاز)
- قسم البث (محتاج نت)

---

## تعديل المحتوى

كل حاجة في `index.html`:

- **الشعار**: `<template id="emblemTpl">` فوق آخر الصفحة.
- **الرتب**: قسم `<section class="section ranks" id="ranks">`.
- **القوانين**: قسم `id="codex"`.
- **لينك الديسكورد**: ابحث في الملف عن `discord.gg` وغيّر اللينك في المكانين
  (زرار الانضمام + الفوتر).
- **التاج**: `id="tagValue"` غيّره لتاج العيلة الحقيقي.
- **الاسم**: ابحث عن `ANARCHY` / `Anarchy` وغيّرهم.

---

## قسم البث (Kick)

بيقرأ من:
`https://kick.com/api/v2/channels/shenzoe`

- لو لايف: بيعرض مشغّل كيك جوه الموقع + عدد المشاهدين + عنوان البث.
- لو أوفلاين: بيعرض بانر القناة و«OFFLINE».
- بيتحدّث تلقائي كل 60 ثانية.

تغيير القناة: في `script.js` فوق خالص:

```js
const LIVE = {
  slug: 'shenzoe',
  ...
};
```

### لو الاستضافة بتمنع الطلب (CORS)

شغّل السيرفر المرفق:

```bash
node live-proxy.js
# ثم افتح http://localhost:8080
```

السيرفر بيقدّم الموقع + `/api/live` (بيانات كيك) من نفس الدومين،
وبيكاش الرد 20 ثانية عشان ما نضربش حد.

---

## حاجات صغيرة تتبسط بيها

- اكتب على الكيبورد كلمة **anarchy** في أي وقت → جليتش في الصفحة.
- زرار **SOUND** فوق بيشغّل دَرون صوتي (اختياري، مقفول في الأول).
- زرار **نسخ** جنب التاج بينسخ على طول.
- الصفحة كلها متظبطة للموبايل.

## رفع الموقع (مجاني)

- **Netlify / Vercel**: اسحب الفولدر كله وخلاص.
- **GitHub Pages**: ارفع الملفات وشغّل Pages.

مش محتاج سيرفر عشان قسم البث في الغالب — المتصفح بيقدر يجيب بيانات كيك
مباشرة. سيرفر `live-proxy.js` للاحتياط لو الاستضافة عاملة حجب.
